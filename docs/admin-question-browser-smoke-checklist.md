# 管理端题库浏览器 Smoke 清单

目的：
- 用最短路径确认本轮题型统一改造在浏览器里可用
- 适合开发自测、提测前快验、联调前走查

建议环境：
- 管理端前端可正常登录
- 后端服务可正常访问
- 已准备一个题库
- 已准备若干知识点

---

## A. 题库管理页 Smoke

### A1. 页面基础可用
- [ ] 打开“题库管理”页无白屏、无明显报错
- [ ] 可正常加载题库下拉
- [ ] 可正常加载题目列表
- [ ] 搜索、题型筛选、状态筛选可操作

### A2. 新建题目
- [ ] 先选择题库，再点击“创建题目”
- [ ] 单选题可正常创建
- [ ] 多选题可正常创建
- [ ] 判断题可正常创建
- [ ] 简答题可正常创建
- [ ] 创建成功后列表立即可见

### A3. 编辑题目
- [ ] 打开已有单选题，回填正确
- [ ] 打开已有多选题，回填正确
- [ ] 打开已有判断题，回填正确
- [ ] 打开已有简答题，回填正确
- [ ] 切换题型后提交仍符合新规则

### A4. 导入
- [ ] 不选题库时，点击导入不可直接上传
- [ ] 可下载“合法示例 JSON”
- [ ] 可下载“混合校验示例”
- [ ] 上传合法文件后成功
- [ ] 上传混合文件后出现“部分失败”提示

### A5. 关系与列表
- [ ] 知识点绑定弹窗可打开
- [ ] 可更新知识点绑定关系
- [ ] 列表答案显示符合题型
- [ ] dirty 状态标签显示正常

---

## B. 知识图谱页 Smoke

### B1. 图谱加载
- [ ] 页面可正常展示图谱
- [ ] 可切换时间范围
- [ ] 可切换“全部 / 知识点 / 题目”
- [ ] 可缩放、重置/刷新

### B2. 节点详情
- [ ] 点击知识点节点可打开详情
- [ ] 点击题目节点可打开详情
- [ ] 详情弹窗可正常关闭

### B3. 题目编辑
- [ ] 题目节点进入编辑后，按题型显示正确控件
- [ ] 单选/多选仅支持 A/B/C/D
- [ ] 判断题只显示对/错
- [ ] 简答题显示文本答案
- [ ] 保存成功后详情更新

---

## C. 最小回归路径

建议按以下顺序做一次最小烟测：

1. 进入题库管理页
2. 创建一个单选题
3. 将它编辑成判断题并保存
4. 绑定知识点
5. 导入一份合法 JSON
6. 导入一份混合合法/非法 JSON
7. 进入知识图谱页
8. 点击刚才的题目节点并再次编辑

---

## D. 通过标准

满足以下即可视为 smoke 通过：

- 页面可打开
- 新建可用
- 编辑可用
- 导入可用
- 图谱页题目编辑可用
- 无阻塞级前端报错
