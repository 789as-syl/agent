# SPEC-08-frontend-integration.md

## 1. 阶段目标
在 API 冻结基础上完成用户端与管理端前端联调。

## 2. 范围
- 用户端：登录、对话、历史会话、Trace 可视化、导出/清空/新建
- 管理端：知识库管理、题库管理、知识图谱、数据看板
- SSE 消费与断线重连
- API 错误处理与降级提示
- 响应式适配

## 3. 注意
- 不允许为迎合前端临时修改后端核心语义
- 仅可做兼容性增强
- SSE 事件按冻结协议消费

## 4. 验收标准
- 用户端核心流程可演示
- 管理端上传/导入/图谱/看板可演示
- 前后端联调问题有清单闭环
